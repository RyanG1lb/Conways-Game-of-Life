Console app created based on the Conways game of life. Grid size is user selected as well as the option for a starting grid pattern. Number of generations is inputted and a final generation is displayed based on the game's 4 rules.

How to play:

Run the console app to prompt the user to input the row and column numbers for the grid.
Input numbers between 5-30
Select the type of starting pattern you'd like: 1 - Randomly generated cells. 2 - 1x3 horizontal line which flips vertical. 3 - Shape that translates itself accross the grid
Input how many generations you want the simulation to run based on the 4 rules of conways game of life
